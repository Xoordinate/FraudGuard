FraudGuard is a real-time fraud and abuse detection platform built for product and trust-and-safety teams. It comes with user agent logging in all plans for robust threat mitigation.

What it does:

Customers send user events — signups, logins, transactions — to FraudGuard via a REST API or JavaScript SDK. The platform instantly scores each event across eight composable detection signals and returns a risk score, a list of triggered signals, and a recommended action: allow, review, or block. The whole round-trip runs in under 50ms.

Detection signals:

Velocity — detects abnormal action rates from the same device or IP.

VPN / Proxy — flags connections from anonymizing infrastructure.

Username & email similarity — spots re-use patterns from previously banned accounts.

Fingerprint matching — links device fingerprints to known bad actors across sessions.

Account age — weighs risk against how recently the account was created.

IP intelligence — cross-references IPs against the project's blocklist in real time.

Key features:

Projects — each project gets its own API key, blocklist, alert feed, detection thresholds, and webhook.

Alerts — every event scoring above 0.2 confidence creates an alert; teams can review, confirm, or dismiss them in bulk with moderator notes.

Blocklist — manually added or auto-promoted from confirmed alerts; blocked users serve as templates for future similarity matching.

Webhooks — projects can subscribe to alert.created and alert.confirmed events above a configurable risk threshold.

Customer portal — customers log in to view their own alerts, billing, and account status
Storefront — a public-facing marketing site with live demo, pricing plans, and a checkout flow.

Who it's for:

Any platform that needs to detect ban evasion, account farming, credential stuffing, or other abuse patterns — gaming, marketplaces, social platforms, financial services.
